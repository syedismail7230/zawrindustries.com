## 🏛️ System Architecture

* **Framework:** Next.js (App Router, Server Components & Actions)
* **Frontend:** React 19, TypeScript, Vanilla CSS Design System, Framer Motion
* **3D Visualizations:** Three.js / React Three Fiber / Spline
* **Database & Realtime:** Supabase (PostgreSQL 15, Row Level Security, Storage, Realtime)
* **Hosting & Edge:** Vercel Edge Runtime & Serverless Functions
* **Email & Telemetry:** SMTP TLS 1.3 Relay + Realtime Supabase Telemetry Store

## 💻 Local Development (Authorized Personnel Only)

1. Clone the repository:
   ```bash
   git clone https://github.com/syedismail7230/zawrindustries.com.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure environment variables in `.env.local`:
   ```bash
   cp .env.example .env.local
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
